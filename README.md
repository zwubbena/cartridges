# Cartridge Line-Up

An interactive study guide to small-arms cartridges: what the parts of a round are, what cartridge names mean, how eighteen common cartridges compare at true scale, how shotgun gauge works, the common bullet constructions, and the ammunition mismatches a firearms safety course covers. A ten-question quiz and a spec table close the page.

Live page: https://zwubbena.github.io/cartridges/

The whole guide is one file, `index.html`, with no build step and no dependencies beyond web fonts.

## Sources and limits

Cartridge dimensions follow the nominal maximums in the SAAMI and CIP cartridge drawings. Typical loads are representative factory figures (rifle-length barrels for rifle cartridges, 4 to 6 inch barrels for handgun cartridges); a manufacturer's own box or data sheet governs for any specific load. Muzzle energy is computed as weight in grains × velocity in ft/s squared ÷ 450,436.

This guide is study material, not a substitute for a firearm's manual or a qualified instructor. Load only ammunition whose headstamp matches the chambering stamped on the firearm.
